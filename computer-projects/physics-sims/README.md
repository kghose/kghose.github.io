## Notes

### 2026.08.28 

Got the urge to do some physics simulations. Two scenarios I want to understand.

I) How does a lopsided spinning spaceship behave: SciFi scenarios have spaceships
spinning on their axis to simulate gravity. How would a) it work with an
asymmetric spaceship e.g. shaped like a hammer and b) how would it work with
thrusters and attitude control, since we now have gyro forces. 

II) Disintegrating body: Spinning body, say an asteroid, suddenly disintegrates.
What does the debris field look like?

Discovered [Project Chrono](http://projectchrono.org/). It configures and
compiles with no fuss. Just had to install `eigen3` and `irrlicht` which were
available on the Fedora repos. The demos work excellently, so will go ahead and
see if I can code up the two simulations rattling inside my head.
